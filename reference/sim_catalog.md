# Print a catalog of available synthetic datasets and files

Print a catalog of available synthetic datasets and files

## Usage

``` r
sim_catalog(dataset = NULL, year = 2023L)

woonbase_catalog(year = 2023L)
```

## Arguments

- dataset:

  Dataset identifier, or `NULL` for all datasets.

- year:

  Year to display in example file names (default 2023).

## Value

Invisibly `NULL`.
